# Dishonored - Dunwall plugin

Shows the Dunwall camp screen on every empty tab. The screen has a clock and a date, six buttons, and short lists of recent notes and bookmarks. Each button can open a note, a folder, or a command.

## Install

1. Install and enable this plugin from Community plugins.
2. Install the Dishonored - Dunwall theme. The plugin needs it for the look and the fonts.
3. Go to Settings, then Appearance, and set the CSS theme to Dishonored - Dunwall.

## Use

The camp opens on empty tabs. To open it again, run the command Return to the camp.

The plugin also has a settings tab, under Dishonored - Dunwall. It holds the colors, the painting, and the button settings. Style Settings works too.

## Notes

The plugin does not style the editor. The theme does that, and the camp screen depends on the theme for its look and fonts.
