# Dishonored - Dunwall plugin

[![Get the theme](https://img.shields.io/badge/Get_the-Dunwall_theme-6b5530)](https://github.com/SentientShawarma/dishonored-dunwall-theme)

This plugin is the helper for the [Dishonored - Dunwall theme](https://github.com/SentientShawarma/dishonored-dunwall-theme). It adds the camp screen and its features. Install it with the theme to get the full experience.

## Install

1. Install and enable this plugin from Community plugins.
2. Install the [Dishonored - Dunwall theme](https://github.com/SentientShawarma/dishonored-dunwall-theme).
3. Go to Settings, then Appearance, and set the CSS theme to Dishonored - Dunwall.

## What the plugin adds

- The camp screen, shown on every empty tab, with a clock and a date.
- Six buttons: The Heart, The Map, The Journal, The Mark, The Ledger, and The Contract. Each one can be shown or hidden, renamed, and set to open a note, a folder, or a command.
- Autocomplete for the note, folder, and command targets on each button.
- A list of your five most recent notes.
- A list of your five most recent bookmarks.
- Smoke fog across the camp screen, with settings for how thick it is and how fast it moves.
- A settings tab under Dishonored - Dunwall. The same settings also appear in Style Settings.
- The "Return to the camp" command, which opens the camp screen again.

## Use

The camp opens on empty tabs. To open it again, run the command Return to the camp.
